## Mandarin sentence

People remember words inside sentences, and a Mandarin card needs script, pronunciation and often audio together. The input is for the moment you have something in hand: a line in a textbook, a sentence you heard, or a word you just looked up.

1. Tap **Add card** in a Mandarin deck.
2. Type or paste the sentence, in characters.
3. Tap the word you're learning. It's what the card tests, and it gets highlighted in the sentence.
4. Type the pinyin for that word. Tone marks or tone numbers: **undecided.**
5. Write what it means, in your own words.
6. **Save card.** The form clears for the next one, like version one.

**Review:** the sentence appears with the word highlighted. You say or think its sound and meaning, then reveal the pinyin and your meaning, and rate it.

**Audio:** recording or playing it is **undecided.** Version one is text only.

**Who uses it in the first month:** a friend taking Mandarin. Name them before building this. If nobody is, it stays unbuilt.

## Math problem

A flashcard shows the same question every time, which trains recognising that one question, not the method. A math card has to come back as a different problem of the same type, mixed in with other types, and accept an answer written several correct ways.

1. Tap **Add problem type** in a math deck.
2. Write one example problem and its answer, for example "Solve 3x + 5 = 20", x = 5.
3. Mark the numbers that can change, and the range for each (3 can be 2 to 9, say).
4. Say how the answer is worked out for new numbers: **undecided.**
5. **Save problem type.**

**Review:** a fresh problem of that type appears, mixed with the deck's other types. You type an answer. The app accepts equivalent forms (½, 0.5 and 2/4), shows whether you were right, and you rate it. Which forms count as equal: **undecided.**

**Who uses it in the first month:** you, if your math class has problem types worth drilling. Name the class before building this.
